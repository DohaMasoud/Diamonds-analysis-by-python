## 💎 Diamonds Price Analysis Project
This project analyzes a diamonds dataset to uncover key insights about pricing and the influence of various physical and quality attributes. 
It also applies machine learning models to predict diamond prices with high accuracy.

## 🔧 Libraries Used
pandas
numpy
matplotlib
seaborn
scikit-learn

## 🔍 Machine Learning Models
#### 1. Linear Regression
R² Score: 0.9816
MSE: 286,787.71

#### 2. Decision Tree Regressor
R² Score: 0.9999
MSE: 1,541.25
#### ➡️ Conclusion: The Decision Tree model significantly outperforms Linear Regression in price prediction.

## 📌 Key Takeaways
Carat weight is the most influential feature in diamond pricing.

Spread factor helps assess how large a diamond appears face-up.

Premium cut and G-H color range provide high-quality diamonds with good price balance.

Decision Tree Regression provides highly accurate predictions for diamond prices.
